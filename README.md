# 🎀 女性向剧情调料

输入框发送键旁边多一颗研钵键。点开选一味料，**下一轮正文自然加进去，只加这一次**；不点就一点都不加。

不用世界书、不用 EJS 插件，任何角色卡都能配。前身是「女性向世界书」（按钮＋一百多条世界书），这一版整个重写了。

## 装法
酒馆助手 → 脚本库 → 导入 → 选 `plot_spice_online.json`（**在线版**：脚本库里只放一个加载器，本体从云端拉，作者更新你不用重导）→ 装到**全局**。
发送键左边出现研钵键就装好了。离线用、不想联网拉代码，就导 `plot_spice_offline.json`（不会自动更新）。

## 三页
- **🧂 加料**：🌶️ 加辣 / 🌀 混乱 / 🎉 节日 / 🍬 日常有趣，再加一排狗血键 🌙 男二 · 👠 女配 · 🥀 男配 · ⚔️ 雄竞 · 💅 雌竞。点一下就从词库里抽一味，模型只拿到抽中的那一个。
  - 盲盒（默认开）：点完不告诉你抽到什么，正文写完才揭晓
  - 余波：加完料后 3 层正文还记得这件事的后果（伤要养、架要和），到期自己撤
- **🎬 剧情**：一叠剧情卡片，按类分：心动推进、他破功、换边、意外、酸涩、哄与和好、推剧情、镜头……点卡片＝下一轮演这个；点卡片右上角 📌＝**常驻**，每一轮都带，直到你在顶上点 × 取消。涩涩卡默认藏着，⚙️ 里打开。最下面能**自己写一句**，装填一次或常驻都行。
- **⚙️ 设置**：盲盒、狗血键、洁党版（酸涩不靠前任和第三者）、危机、脑洞、余波、涩涩卡、校园/职场场景佐料。

## 小细节
- 装填了还没发的时候，研钵键右上角有个小粉点；顶上能看到装了什么，点 × 撤掉
- 刷新页面、换聊天再回来，装填的料和常驻都还在（存在这个聊天里）
- 对刚加过料的那一楼重抽 / 滑动，会把同一味料再塞一次，不会抽着抽着料没了
- 它只动「下一轮发给 AI 的提示」，不改你的聊天记录，也不改角色卡
